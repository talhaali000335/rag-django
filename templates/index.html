Setup Guide

Steps to get your RAG API fully working.

1. Enable CORS for your frontend

Add this to your production Django settings so the browser can call your API:

CORS_ALLOW_ALL_ORIGINS = True # or restrict to specific origin: CORS_ALLOWED_ORIGINS = ["http://your-frontend.com"]

File: config/settings/base.py

2. Create a superuser

Run this in your ECS container to create an admin account:

aws ecs execute-command \ --cluster rag-cluster \ --task <TASK_ARN> \ --container rag-api \ --interactive \ --command "python manage.py createsuperuser"
3. Your API endpoints

All endpoints require a JWT token except health:

POST /api/token/ → Get JWT token (login) POST /api/token/refresh/ → Refresh token POST /api/chat/ → Ask a question POST /api/documents/upload/ → Upload a PDF GET /health/ → Health check GET /admin/ → Django admin UI
4. Visit Django Admin

The admin panel lets you manage users and documents in a visual UI:

http://44.205.21.89:8000/admin/
